🛒 Amazon Clone Website


An Amazon Clone website created using HTML and CSS.

This project replicates the UI and layout of the Amazon homepage to practice frontend development skills and improve understanding of responsive web design.


🚀 Features:

🧱 Amazon-like homepage layout

🛍️ Product cards and categories section

🔍 Search bar design

🧭 Navigation bar (Header & Footer)

📱 Responsive layout (basic)

🎨 Clean and modern UI using CSS


🛠️ Technologies Used:

HTML5 – Page structure

CSS3 – Styling and layout (Flexbox/Grid)
